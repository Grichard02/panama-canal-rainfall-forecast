Desarrollé un proyecto de ciencia de datos enfocado en la predicción de precipitaciones en el área del lago Gatún, utilizando datos meteorológicos históricos de NASA POWER.

El objetivo fue evaluar cómo los modelos estadísticos y de Machine Learning pueden contribuir al análisis de variables ambientales relevantes para la gestión de recursos hídricos.

Utilicé Python para obtener y procesar los datos, realizar análisis exploratorio, identificar patrones estacionales y entrenar un modelo Random Forest.

Para evaluar su desempeño, utilicé métricas como MAE y RMSE y comparé los resultados con un modelo base estacional.

También implementé un procedimiento de pronóstico a varios meses y documenté las limitaciones del modelo, especialmente la incertidumbre asociada a las predicciones de precipitación.
